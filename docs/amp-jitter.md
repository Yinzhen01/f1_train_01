- 三个窗口记录到的右足最大Fz分别约5076、3111、2400N；原始记录是100Hz末端
  net force，尚不能声称是1kHz真实峰值或已分离地面/自碰撞的接触力。
- 当前动作平滑奖励存在，但三个窗口均值仅−0.000173、−0.000209、−0.000292/步；
  前进奖励约+0.0103、+0.0155、+0.0137，AMP约+0.00622、+0.00823、+0.00839。
  加速度鲁棒惩罚使用100Hz端点差分，且大值区为线性尾段。力矩变化率没有独立奖励。
  这些是监督不足的具体线索，因果效果仍需干预实验验证。
- 踝关节目标频繁超出URDF角度范围，但实际关节通常未贴硬限位；PD目标也承担
  施加载荷的作用，不把目标超限误判成实际关节超限，不直接硬裁剪策略输出。

### 新证据：端点差分遗漏子步波动

来源：`outputs/amp-jitter/substep-2750/substep_audit.json`。
使用新增真实子步统计；每个初态对齐到两组较早结束时刻，排除重置和前2秒。
两组均保留所有32初态。以下为逐初态计算后等权平均，不与缺少1kHz记录的源模型硬比较。

| 同区间指标 | 对照 | 平滑 |
| --- | ---: | ---: |
| 100Hz端点加速度RMS rad/s² | 61.86 | 55.31 |
| 1kHz子步加速度RMS rad/s² | 157.16 | 149.38 |
| 端点均方/子步均方 | 15.60% | 13.67% |
| 无任一足部1100N尖峰区间的子步加速度RMS | 74.43 | 73.59 |
| 子步峰力>1100N、末端却≤1100N的足-区间比例 | 88.79% | 88.75% |

100Hz端点速度差分等于十个子步加速度的均值；先平均再平方会使正负波动相消。
这里的均方比不是“漏掉多少真实运动”的百分比，也不能从最大值恢复完整子步波形。
1100N仅用于诊断分类，不是步态相位或真正触地事件计数；net force未区分接触对。
即使排除大力区间，两组子步加速度也相近，说明统一动作平滑没有明显解决剩余物理波动。

### 失稳链条

对照reference env12在33.01秒失败。平滑standing env3在2.72秒、reference env10在6.21秒、
standing env10在56.66秒失败。四条真实轨迹均出现前向速度下降、转负，随后姿态/高度崩溃。
例如平滑reference env10在失败前3–1秒平均vx .263m/s，末值已−.121；
最后1秒平均vx−.744，根高度最低.286m，pitch约−37.8°，并伴随侧倾。
代表帧与原始曲线一致；失败不只是视频抖动或编码问题。

推论：当前策略依赖的快速纠偏与平滑目标可能冲突；续训也存在步态漂移。
现有单种子对照不足以分离二者贡献，不能断言每次跌倒都由平滑惩罚直接造成。
