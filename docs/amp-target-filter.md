# 固定目标带宽实验（23/24）

## 动机与边界

第19–22轮尚未消除抖动，细节见[原抖动分析](amp-jitter.md)和[子步实验](amp-substep.md)。
高频策略指令经PD位置项直接变为快速力矩变化；增加奖励权重曾出现减速或跌倒，
子步惩罚也没有稳定改善无大冲击时段。本轮直接改变确定性控制带宽，再训练适应。
这是假设驱动实验，不是已验证的根因修复。

## 两组定义

|组|截止参数|alpha|10Hz幅值增益|低频群延迟|
|---|---:|---:|---:|---:|
|target5（23轮）|5Hz|0.2696|0.455|约27ms|
|target8（24轮）|8Hz|0.3951|0.635|约15ms|

每10ms，先按原范围裁剪策略动作，再计算`y=alpha*raw+(1-alpha)*previous_y`，
`alpha=1-exp(-2*pi*fc*0.01)`。所有12关节使用同一标量参数；每次reset将状态归零，
对应默认关节目标。以上增益和延迟来自离散滤波器计算，不是机器人闭环实测。

`env.actions`、PD和原动作历史观测使用实际施加的y；PPO保存原采样动作和对应logprob，
不原位修改采样tensor，不新增观测维度。奖励表达式/权重不改，原动作平滑项监督实际施加指令。
额外逐帧保存raw与previous_y，离线验证递推和状态连续性；1kHz物理量继续只读捕获。

固定滤波不是DR，但增加了真实控制延迟，可能导致跌倒。新模型只能配合同样的滤波器使用，
不能直接把旧部署脚本换上新权重；本轮录制来自相同Isaac Gym控制器，视频本身不做运动平滑。

## 原因解释与后续边界

已验证：滤波确实生效，策略原始输出和施加输出都已保存，未修改PPO样本/logprob。
8Hz施加指令高频功率约−92%，但实际加速度、冲击和整体稳定性并未改善。
因此“压掉高频目标就能解决物理抖动”不足以解释当前系统。

合理推断：全关节低通同时延迟了平衡调整；接触瞬态及变化后的步态仍可产生很大
加速度，且原策略在250次更新内没有充分适应新控制器。8Hz组出现了向前冲后跌倒和
减速后倒两类失败，不能统一解释为停步。固定延迟、学习更新和接触响应各自的贡献
尚未被单独分离，不声称发现唯一根因。

本轮不再降低全关节截止频率，不提升043/044，不解锁DR。
后续先回到原2500诊断接触瞬态和续训漂移，保留快速平衡反馈；任何新方案仍需独立短测
及相同32初态评估，不以视频变顺或训练奖励上升作为验收。抖动目标尚未完成。
